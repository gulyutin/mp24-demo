# mp24-demo

Ветка `gh-pages` — зашифрованный сайт «Медиаполе24» (обновляется автоматически, вручную не редактируется).

Ветка `main` — только будильник `.github/workflows/wake.yml`: раз в сутки запускает ежедневный прогон
в частном репозитории `gulyutin/media-pulse24`. Для работы нужен секрет `WAKE_TOKEN`.
